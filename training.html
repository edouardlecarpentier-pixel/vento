🔗Connexion Strava

Première connexion : créer ton application Strava (2 minutes)
  1. Ouvre strava.com/settings/api et crée une application (nom : Vento, catégorie : Training, site web : http://localhost:8765).
  2. Dans Authorization Callback Domain écris exactement : localhost (sans https://, sans /).
  3. Copie le Client ID (un nombre, par exemple 123456) et le Client Secret (40 caractères), colle-les ci-dessous : ils restent dans ton navigateur.
  4. Ouvre cette page à l'adresse http://localhost:8765/training.html puis clique « Se connecter à Strava ». Le domaine de rappel doit être celui de l'adresse de cette page.

Séances pour ton home trainer

Chaque séance se télécharge en fichier d'entraînement : ZWO (Zwift, MyWhoosh, TrainingPeaks Virtual, Intervals.icu…), MRC (en % du FTP) ou ERG (en watts). Les intensités sont calculées pour un FTP de W : règle le même FTP dans ton application de home trainer. La résistance suit alors automatiquement les paliers de la séance.

Ces conseils sont des repères généraux calculés à partir de tes données, pas un programme de coach personnalisé. Écoute ton corps, adapte en cas de fatigue ou de douleur et demande un avis médical au moindre doute.
