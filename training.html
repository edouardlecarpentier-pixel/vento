🔗Connexion Strava

Première connexion : créer ton application Strava (2 minutes)
  1. Ouvre strava.com/settings/api et crée une application (nom : Vento, catégorie : Training, site web : http://localhost:8765).
  2. Dans Authorization Callback Domain écris exactement : localhost (sans https://, sans /).
  3. Copie le Client ID (un nombre, par exemple 123456) et le Client Secret (40 caractères), colle-les ci-dessous : ils restent dans ton navigateur.
  4. Ouvre cette page à l'adresse http://localhost:8765/training.html puis clique « Se connecter à Strava ». Le domaine de rappel doit être celui de l'adresse de cette page.

🚴 Séances pour VeloIndoor (ton appli reliée au home trainer)

Le bouton 🚴 VeloIndoor ouvre ton application avec la séance déjà chargée (étapes en watts pour un FTP de W) : il ne reste qu'à connecter le home trainer et à démarrer. Sur Android, l'application installée s'ouvre ; sinon, la version web de VeloIndoor s'ouvre. 📋 Copier met la séance dans le presse-papiers (VeloIndoor : « Importer depuis Vento »).

Autres applications : ROUVY

Chaque séance se télécharge en fichier d'entraînement que ROUVY sait importer (.erg, .mrc ou .zwo). Le bouton ROUVY (.erg) donne les watts exacts calculés pour un FTP de W. Les formats ZWO et MRC sont en % du FTP : dans ce cas, règle le même FTP dans ton profil ROUVY.

  1. Télécharge la séance (bouton « ROUVY (.erg) »).
  2. Sur le portail ROUVY : onglet Workouts → Import from file. Dans l'application ROUVY : onglet Workouts → « Add your own workout » → Import from file.
  3. Ouvre la séance dans ROUVY et touche Change pour choisir le parcours à rouler pendant les paliers.

Besoin d'un parcours précis ? Dans le planificateur, exporte ton tracé en GPX puis importe-le dans le portail ROUVY (onglet Routes → Import from file).
